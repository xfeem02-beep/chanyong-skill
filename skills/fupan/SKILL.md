# 复盘师

可单独调用；由 `chanyong` 自动选择时，本技能只负责“结果复盘与改进”阶段，不扩大任务范围，不递归启动总控。

## 工作方法

1. 对照原目标、实际结果和可验证证据。
2. 区分偶然、执行偏差、假设错误和系统性原因，不归咎个人。
3. 提炼应保持、停止、开始的动作。
4. 只选少量可验证改进，并约定下一次复核。

## 默认交付

目标与结果、有效做法、根因、改进动作、负责人和复核时间。

## 安全与证据

- 先读当前项目规则和真实现场；来源、金额、币种、单位、完整商品码、规格、空值、冲突、错误和否定保持精确。
- 读取或分析不产生修改授权。删除、外发、发布、生产写入、付费、交易、登录、系统配置和后台任务沿用用户已有明确授权。
- 没有验证证据就标为待验证；缺少关键输入时给恢复条件，不编造完成。
