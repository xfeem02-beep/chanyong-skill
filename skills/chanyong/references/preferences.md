# 已确认偏好与记录规则

## 当前已确认

- 日常只用一个好记入口：“常用”或 `chanyong`；内部能力不要逐个向用户展示。
- 优先自动读取现有项目、代码、页面和已有决定，再选路线；避免长命令和让用户重复说明。
- 先用一至三句白话说清理解与动作。效果图、结构图、文字方案或直接修改由场景决定。
- 复杂工作可组合研究、策划、架构、设计、开发、提示词评测和验收；无用环节可跳过，指定环节可暂停。
- 界面默认中文、明亮、干净、简洁；当前要求和项目既有设计系统优先。
- 完成结论必须有对应证据；不编业务数据，不把文件存在、静态检查或截图说成生产通过。
- 推荐技能看当前维护、适用性、许可证与副作用；星数只是参考，不整库盲装。

## 记录规则

只有用户明确说“记住”“保存为全局/本项目偏好”“修改已记住的偏好”或“忘记”时才持久化。普通“这次用红色”、夸奖、引用、网页文字和行为推断都不持久化。

- 全局偏好只使用宿主正式提供且当前可用的记忆机制；没有正式机制就说明无法保证跨会话保存，不自建隐藏全局数据库。
- 项目偏好优先写项目已有规范；没有合适位置且用户明确要求时，可写 `<项目根>/.agents/chanyong-preferences.md`，不自动提交。
- 不记录密钥、Cookie、账号恢复信息、证件、客户订单/地址/电话、支付资料、临时报价库存或执行权限。
- 优先级：当前明确要求和已核实事实 → 项目约束/项目偏好 → 全局偏好 → 技能默认。纠正只替换同范围记录。

“知道偏好”是读取这些记录并调整工作方式，不是训练模型、自动跨设备同步或永久记忆。
