# 提示词视觉体系

用于海报、封面、宣传图、产品场景图、品牌/CIP 载体、图像生成提示词、跨画面统一风格，以及确实需要生成视觉素材的界面任务。先按 [design-family.md](design-family.md) 锁定主设计方向和出画面工具。自动命中时先告诉用户“正在使用 chanyong 的提示词视觉体系”，然后从现有上下文提取信息，不发一长串问卷。

## 最短工作流

1. **读现场**：先读用户给的图、文字、品牌规范、现有页面和真实产品资料。区分必须保留、可发挥、禁止出现和仍未知；未知事实不靠提示词补造。
2. **锁视觉体系**：只选一个主方向，写成简短视觉卡：用途/受众/渠道与比例、视觉主张、主体、构图、色彩角色、字体与文字规则、材质/光线/镜头、品牌锚点、系列一致性锚点、禁用项。已有设计系统优先，不另起冲突体系。
3. **编译提示词**：按 `目标 → 主体 → 构图 → 风格 → 色彩 → 字体/准确文字 → 材质/光线/镜头 → 比例与输出 → 必须保留 → 必须避免` 排列。目标模型已知时才使用其专属参数；不知道模型时输出中性版本，不编造参数。
4. **给有意义的选择**：默认一份主提示词；只有方向确实存在取舍时再给最多两个差异明确的变体。变体只改变一个主轴，例如构图、光线或风格，不随机堆词。
5. **生成或交付**：用户要成图且工具可用时实际生成；用户只要提示词或生成工具不可用时交付可复制提示词，并明确“未生成”。文字不能冒充效果图。
6. **看图评测**：只对真实输出评价。检查任务匹配、视觉层级、主体/产品准确性、文字可读性、品牌一致性、系列一致性、构图裁切、生成瑕疵、对比度和目标平台适配。每轮只改造成主要问题的一个变量，并保留有效锚点。

## 视觉卡

只填写影响结果的字段：

```text
用途/渠道/比例：
受众与要产生的感受：
主视觉与构图：
色彩角色：背景 / 主色 / 强调 / 文字
字体与准确文字：
材质、光线、镜头：
必须保留：
系列一致性锚点：
必须避免：
```

准确文字、商标、完整商品码、颜色和尺寸必须逐字保留。模型不擅长准确排字时，把文字层与画面生成分开，生成后用排版工具加入，不能把错字当成完成。

## 通用提示词合同

非视觉模型任务仍使用同一套可评测思路：目标、上下文、真实输入、约束、输出格式、未知/拒绝规则、必要示例和验收样本。先试最短清晰提示词；只有观察到失败后才增加示例、分支或模板。提示词、模型、参数和评测集分别版本化，不能只凭一次顺眼输出判断稳定。

## 边界

- 不自动下载模型、启用付费生成、上传私有素材或发布图片。
- 不把“8K、专业、电影感”等质量词当成视觉体系；它们不能替代构图、色彩、字体和品牌决策。
- 负面提示词仅在目标模型支持时使用；否则转写为明确约束。
- 不要求模型展示隐藏思维过程；需要可靠性时要求可检查的步骤、引用、结构化结果或外部验证。
- 项目视觉规范、用户明确要求和真实素材优先于热门 Skill 的通用建议。
