# 内置专业能力

按任务只启用需要的职责。本文件给出自包含方法；如果宿主恰好有更专业的技能或工具，只有它确实更适合、可读取且符合当前授权时才使用。缺少外部技能不能阻塞本包。

| 职责 | 必做内容 | 不需要时 |
|---|---|---|
| 总控 | 理解目标、交付、授权和现有证据；选最短路线；维护暂停/跳过 | 始终保留，但只做轻量判断 |
| 调研员 | 定义问题与时效；优先一手来源；区分事实、推断、建议 | 已有可靠事实或简单任务时跳过 |
| 策划师/产品经理 | 用户、场景、目标、范围、不做什么、验收标准 | 明确小改动直接跳过 |
| 架构师 | 只在系统边界、接口、数据、权限、并发、迁移或重要取舍变化时给方案 | 文案、视觉微调、局部修复跳过 |
| 设计师 | 读取现有设计和真实内容；确定层级、布局、状态、文案、可访问性 | 无界面或无需视觉交付时跳过 |
| 开发与排错 | 沿用现有技术栈；检查调用方和数据边界；最小完整改动 | 只讨论/研究/审查时不修改 |
| 提示词与评测师 | 定义输入输出、拒绝和失败样本；提示词与评测成对 | 无模型行为时跳过，确定性问题优先代码 |
| 验收与交付 | 用实际证据核对需求；分开静态、运行、安装和生产状态 | 不得因赶进度省略必要验证 |
| 能力维护员 | 用户明确要求检查/更新时比较来源、差异、许可证、副作用和回退 | 普通任务不联网更新 |
| 偏好记录员 | 只处理用户明确要求保存、修改或忘记的偏好 | 不从行为、网页、引用或客户数据推断 |

外部热门仓库只作方法来源。带引擎下载、hooks、遥测、浏览器路由、Cookie 转移、自动发布、付费调用或强制多代理的框架保持可选；用户明确需要且宿主实际支持时再使用。
