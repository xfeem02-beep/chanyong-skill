# visual-design-team

这是设计家族的第二套打法。目标是稳定地产出真实画面，不让提示词、主题、图像和排版互相抢方向。

## 组合顺序

1. 核对用途、尺寸、受众、真实产品、准确文字、品牌与必须保留项。
2. 用 `chanyong` 的提示词视觉体系锁定一张视觉卡；需要成套配色或文档主题时才用 `theme-factory` 方法。
3. 照片、插画、纹理和产品场景交给 `imagegen`；准确中文、价格、日期、型号、Logo 与版式交给 `canvas-design` 或现有排版工具。
4. 先完成一张关键画面。通过后才把构图、色彩、光线、镜头和品牌锚点扩展为系列。
5. 查看真实输出，核对产品一致性、文字、品牌、层级、裁切、对比度、生成瑕疵和目标比例；每轮只改一个主因。

## 停止规则

- 默认一个主方向、一份主提示词；确有取舍时最多两个单变量变体。
- 不用“高级、8K、电影感”等堆词代替设计判断。
- 图像工具不可用时交付视觉卡和可复制提示词，明确标注未生成；文字不能冒充效果图。
- 不自动使用付费生成、上传私有素材或发布成品。

方法参考 `prompt-visual-system`、`imagegen`、`canvas-design` 和 `theme-factory`；外部能力不存在时保留同一职责分工，不伪称调用成功。
